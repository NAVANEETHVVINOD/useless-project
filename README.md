# Kanya - Tinder for Pets

Kanya is a premium, beautifully crafted pet social discovery platform that connects pet owners for meaningful friendships and playdates. 

![Project Overview](https://img.shields.io/badge/Status-Production_Ready-success) ![Tech Stack](https://img.shields.io/badge/Tech-Next.js_|_React_|_Tailwind-blue)

## Motivation

Pet owners face real challenges when trying to socialize their pets—unpredictable meetups at parks, mismatched energy levels, and safety concerns. Kanya solves this by providing high-fidelity matching based on breed, temperament, energy level, and location, built on a trusted, verified community network.

## Features Features
- **Smart Pet Matching**: Advanced algorithm for finding compatible playmates based on comprehensive personality traits and filters.
- **Verified Community Ecosystem**: Verified owner profiles and active moderation to ensure meetup safety.
- **Location-based Discovery**: Real-time matching within defined geographic radii.
- **Dynamic Event Hosting**: Integration for local pet events, community walks, and group playdates.
- **Rich User Interface**: Fluid animations (Framer Motion), interactive swipe cards, responsive modern design, and highly polished landing marketing.

## Design Philosophy
We adopted a state-of-the-art cinematic and dynamic design system using custom CSS variable tokens. 
- **Palette**: Earthy and energetic tones (Primary Green `#8FBF5F`, Secondary Brown `#7A5230`, Cream Bg `#F7F7F2`).
- **Aesthetics**: Glassmorphism, subtle micro-animations, layered shadows, and responsive spatial rhythm. 
- **Performance**: Mobile-first fluid layout and server components prioritized for speed.

## Quick Start
```bash
# Clone the repository
git clone https://github.com/NAVANEETHVVINOD/useless-project.git

# Install dependencies
npm install

# Start development server
npm run dev
```

## Production Build
```bash
# Build for production
npm run build

# Start production server
npm run start
```

## Tech Stack
- **Framework:** Next.js 15+ (App Router)
- **Styling:** Tailwind CSS, PostCSS
- **Components:** Shadcn/UI, Radix Primitives
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Type Safety:** TypeScript, Zod validations

## Project Structure
- `app/` - Next.js App Router (Pages, Layouts, APIs)
- `components/` - React components (Landing, UI, Layouts, Auth)
- `lib/` - Utilities and configuration
- `public/` - Static assets and SVG illustrations
- `tests/` - Jest test files
